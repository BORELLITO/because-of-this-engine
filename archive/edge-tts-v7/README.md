# Archived Edge TTS V7 adapter

This adapter was the previous V7.1 runtime. It is retained only for audit and
an explicit reviewed rollback. It is not referenced by the active policy,
orchestrator, manifests or workflows.

The adapter depended on the Microsoft Edge online voice catalog. The canonical
Piper migration replaced it after the catalog endpoint was unavailable in the
production preview environment. No automatic fallback to this adapter is
permitted.
